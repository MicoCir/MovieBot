# Guía del LogBook

El LogBook registra de forma breve la evolución del proyecto.

Cada entrada debe incluir únicamente:

## Entrada <ID>

**Sprint:** <número o nombre del sprint>  
**Tarea:** <nombre de la tarea>

### Resumen

Breve descripción de los cambios realizados, las decisiones relevantes y el resultado obtenido.

---

## Criterios

- Usar un identificador numérico consecutivo.
- No incluir fecha ni hora.
- Mantener cada entrada breve y esquemática.
- Registrar solo información relevante para entender la evolución del proyecto.
- Evitar detalles de implementación menores, etiquetas y apartados innecesarios.
